# 目标：整体销量与渠道表现

## 分析思路

先看总量再看结构：按报告月取 [METRIC-001] 总销量与 [METRIC-003] 环比，确立"这个月卖得怎么样"的事实；再沿 track_sales_month 的渠道枚举（三渠道全集）逐渠道套用同一口径取数，落盘 渠道销量分布.csv。销量占比在落盘前完成计算（该列进直读契约，模板侧不现算占比）。报告月沿用 yyyyMM 字符串格式，sales_qty 的 NULL 表示未开票、不计数（与 [METRIC-001] 口径一致）。

## 数值清单

| 报告数值 | 取数口径（过滤 → 聚合 → 公式） | 依赖指标 |
|---|---|---|
| 当月总销量 | biz_month = 报告月 → SUM(sales_qty)，NULL 未开票不计数 | METRIC-001 |
| 各渠道销量 | biz_month = 报告月 AND channel_name = 该渠道 → SUM(sales_qty) | METRIC-001 |
| 各渠道收入 | 同上过滤 → SUM(sales_amount) | METRIC-001 |
| 渠道销量占比 | 该渠道销量 ÷ 当月总销量（先聚合分子分母再相除） | METRIC-001 |
| 整体环比 | (报告月 [METRIC-001] − 上月 [METRIC-001]) ÷ 上月 [METRIC-001] | METRIC-003 |
| 渠道环比 | 同整体环比公式，渠道内取数计算 | METRIC-003 |

## 用到的表

- track_sales_month

## 产出物

- **渠道销量分布.csv**：3 个渠道行 × 4 列（渠道 / 销量 / 收入 / 销量占比），按销量降序；占比保留 4 位小数
- **整体销量结论**：总销量 + 环比数值与升降判定（引用具体数值）
- **渠道表现结论**：逐渠道量级与环比方向（引用具体数值）
