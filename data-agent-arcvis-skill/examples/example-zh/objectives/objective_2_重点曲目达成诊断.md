# 目标：重点曲目达成诊断

## 分析思路

承接目标 1 确立的报告月与 NULL 口径，聚焦"目标完成得怎么样"：以目标表当月曲目全集为判定范围（覆盖全部上架曲目），逐曲目取当月销量（[METRIC-001] 曲目粒度），与目标量相除得达成率（[METRIC-002]）；达成率升序落盘 曲目达成明细.csv，最未达标曲目排在最前，供报告直接消费。整体达成率在曲目全集上先聚合分子分母再相除，禁止对曲目达成率求平均；目标缺失的曲目记 "—" 单列，不并入也未达标。

## 数值清单

| 报告数值 | 取数口径（过滤 → 聚合 → 公式） | 依赖指标 |
|---|---|---|
| 曲目当月销量 | biz_month = 报告月 AND track_id = 该曲目 → SUM(sales_qty) | METRIC-001 |
| 曲目达成率 | 曲目当月销量 ÷ 曲目当月目标（NULLIF 防除零，先聚合再相除） | METRIC-002 |
| 判定 | 达成率 >= 1.0 达标 / < 1.0 未达标 / 目标缺失 "—" | METRIC-002 |
| 整体销量达成率 | 全曲目当月销量合计 ÷ 目标合计（先聚合分子分母再相除） | METRIC-002 |
| 未达标曲目占比 | 未达标曲目数 ÷ 参与判定曲目数（"—" 行不参与） | METRIC-002 |

## 用到的表

- track_sales_month
- track_target_month

## 产出物

- **曲目达成明细.csv**：120 个曲目行 × 6 列（曲目编号 / 曲目名称 / 当月销量 / 当月目标 / 达成率 / 判定），达成率升序、"—" 行居末
- **整体达成结论**：整体达成率 + 未达标数量与占比（引用具体数值）
