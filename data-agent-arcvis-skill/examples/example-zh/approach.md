# 分析思路

**核心原则**：

- 总量先行、结构其次、目标诊断收尾：先 [METRIC-001] 确立报告月总量事实，再渠道拆解，最后 [METRIC-002] 达成诊断；
- 率类非可加：占比、达成率、环比一律先聚合分子、分母再相除，禁止对率本身 SUM/AVG；
- 判定范围 = 目标表当月曲目全集，禁止抽样：报告明细必须全量落盘，由门禁保证；
- 报告数字与分析产物物理同源：渠道分布与曲目明细落盘后经 $read 直读进网页报告，不经 LLM 复述；
- sales_qty 的 NULL 表示渠道当月未开票（≠ 0），求和时不计数；0 是确认零销量，正常参与求和。

**执行顺序**：objective_1（整体销量与渠道表现）→ objective_2（重点曲目达成诊断，沿用目标 1 确立的报告月与 NULL 口径）。

**通用注意事项**：报告月参数沿用 yyyyMM 字符串格式（如 202512）；环比的上月 = 报告月前一自然月，由执行者推导。

## 指标计算总纲

| ID | 名称 | 公式 | 口径 |
|---|---|---|---|
| METRIC-001 | 当月销量 | SUM(sales_qty)（biz_month = 报告月，可按渠道/曲目粒度套用） | NULL 表示未开票不计数，0 表示确认零销量 |
| METRIC-002 | 销量达成率 | 当月销量 ÷ 当月目标（NULLIF 防除零，分子分母先聚合再相除） | 跨表按 月份+曲目 对齐；>= 1.0 达标；率不可加 |
| METRIC-003 | 销量环比增长率 | (本月销量 − 上月销量) ÷ 上月销量（NULLIF 防除零） | 上月 = 报告月前一自然月；上月为 0 或 NULL 记 "—" |
