# 月度音乐零售销售报告（文字报告要求）

## 报告结构（三章，顺序固定）

### 第 1 章 整体销量表现

本章必含素材：

- 当月总销量与销量环比增长率（数值 + 升降判定）——来源：objective_1/G2

### 第 2 章 渠道结构分析

本章必含素材：

- 渠道销量分布表（渠道 / 销量 / 收入 / 销量占比，三渠道全集）——来源：objective_1/G1
- 逐渠道表现结论（量级 + 环比方向，引用具体数值）——来源：objective_1/G3
- 渠道销量分布横向条形图（规格见 objective_1 图表方法论）——来源：objective_1/G1

### 第 3 章 重点曲目达成诊断

本章必含素材：

- 曲目达成明细表（曲目编号 / 曲目名称 / 当月销量 / 当月目标 / 达成率 / 判定，达成率升序）——来源：objective_2/G1
- 整体达成结论（整体达成率 + 未达标数量与占比）——来源：objective_2/G2

## 语气风格

- 管理层汇报体：结论先行、数值支撑，每章首段一句话结论；
- 数值精度：销量为整数（份），收入保留 2 位小数（元），占比与达成率按百分比保留 2 位小数（如 87.50%）；
- 判定用词固定：达标 / 未达标 / —（目标缺失），禁止"基本达标""接近达标"等模糊表述。

## 格式模板

- 每章以「## 第 N 章 {章名}」起头，先一句话结论段，后接素材表格与展开段落；
- 表格表头与素材清单列名逐字一致；图表仅第 2 章渠道分布一张，规格见 objective_1 图表方法论；
- 禁止出现素材清单之外的图 / 表 / 结论。
